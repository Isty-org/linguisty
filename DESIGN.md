# Linguisty — Retro Orbit Editorial

По прямому запросу пользователя интерфейс переведён с Cloudline на приложенную дизайн-систему. Полный исходный референс: [Isty Retro Orbit](docs/design/isty-retro-orbit-reference.md); прежний источник сохранён как [superseded Cloudline](docs/design/isty-cloudline-superseded.md). Эти документы — визуальные источники, а продуктовые требования и границы задают пользователь и `specs/`.

## Применение к расширению

Продукт остаётся **Linguisty**, Chrome/Firefox desktop, BYOK. Пользователь предоставил отдельный логотип Linguisty в цветном и монохромном вариантах; рядом указывается название продукта. Isty — авторская подпись внизу интерфейса. Лендинг, человеческий постер, маркетинговый слоган и бизнес-позиционирование из референса не являются запросом на новые функции расширения.

Popup компактный, около 390 px: небольшая шапка с брендом, затем сразу языки, модель, реальный статус и основное действие. По уточнению пользователя крупный вводный баннер и его пояснение удалены из popup. Настройки сохраняют редакционный заголовок, спокойный бумажный/графитовый фон, навигацию по реальным разделам и прямоугольные панели. Разделы: сервис/ключ, модель, перевод, интерфейс, локальные данные. На узком экране навигация переходит в горизонтальную строку, поля располагаются в одну колонку.

Обычный текст имеет контраст минимум 4.5:1. Светлые акцентные цвета не используются для мелкого текста на бумаге. Error и focus остаются явными и доступными.

## Типографика и графика

Onest variable и JetBrains Mono поставляются локально в `public/fonts` вместе с SIL OFL. Заголовки Onest italic/800, короткие строки, line-height не ниже 1.04 для кириллицы. Текст интерфейса 13–15 px, спокойный line-height; mono только для номеров, метрик и ID. Для других систем письма работают системные fallback.

В шапке popup/options рядом с названием Linguisty и подписью продукта отображается его логотип: `public/brand/linguisty-monochrome.svg` в светлой теме, `public/brand/linguisty-color.svg` в тёмной. Исходные SVG сохраняют геометрию и цвета пользователя. Размер — 64×64 px в настройках, 44×44 px в popup; соседнее название уже доступно screen reader, поэтому декоративный знак скрыт от него. PNG toolbar icons 16/32/48/128 px воспроизводимо строятся из цветного Linguisty на графитовой подложке, без дополнительной орбиты.

SVG Isty в `public/brand/isty-logo.svg` находится внизу popup/options как небольшая авторская отметка с локализованным «Powered by» (русский: «Разработано»). Он отображается маской: violet в тёмной теме и violet-2 в светлой, имеет доступное имя Isty. Перевод шаблона определяет порядок текста и знака для каждого языка; имя бренда не переводится. Орбиты и лёгкая печатная фактура реализованы CSS без сетевых изображений, больших растров и непрерывной анимации.

## Компоненты и состояния

Кнопки прямоугольные, основная CTA — violet/sage gradient с тёмным текстом, без перемещения на hover и без внешнего glow. Panels и fields имеют тонкую рамку. Содержимое панелей — реальные настройки, данные или состояние процесса. Click targets минимум 44 px; нативные labels, focus-visible, keyboard, progress/error aria-live и reduced motion сохраняются.

Две равноправные темы: **Бумага / Paper** и **Графит / Graphite**. `system` следует цветовой теме системы. Язык UI определяется независимо от языка перевода; длинные названия и RTL не должны ломать layout.
