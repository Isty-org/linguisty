WI-031. Проверены именно production каталоги `.output/chrome-mv3` и `.output/firefox-mv3` после финальных сборок координатора. Браузеры: Chromium 152.0.7977.8, Firefox 157.0.1, geckodriver 0.37.1. Новый `tests/e2e/locale-loading.test.mjs` наблюдает в Chromium: при старте ни одного такого chunk, при выборе `de` только `de`, при выборе `fr` offline только `fr`.
- Предыдущий полный browser evidence относился к пакету 0.4.6 → Chrome, Firefox, подписка ChatGPT с mock, языки/RTL и startup проверены заново на 0.4.7.

ZIP созданы координатором без пересборки. В каждом 56 файлов побайтно совпадают с production каталогом по SHA-256: Chrome ZIP 492 722 байта, SHA-256 `6E7F24054DEE30CFAA33E7E1723BA51B6CA3A78B0F0E80B1C3A871804EC9C277`; Firefox ZIP 492 808 байт, SHA-256 `CECEF8C158F9CBCD28BDFCF4DD9DB2B58C4844BC03CBFE3F5F5C85217F52B763`.

Playwright ожидал отсутствующую Chromium revision 1243. Первоначальный preflight завершился FAIL до запуска браузера. Повтор с уже установленным Chromium 152.0.7977.8 (`LINGUISTY_CHROMIUM_EXECUTABLE`) прошёл fixture/gallery/form; зависимости и браузеры не устанавливались. Первые прогоны нового locale harness дали FAIL из-за предположений о `en` по умолчанию и доступности dynamic imports через Resource Timing. Изолированные браузеры выбрали `ru`; Resource Timing не показал module imports. Harness исправлен: допускает eager `en/ru`, для Chromium использует события `BrowserContext.on('request')`, для Firefox не выдаёт отсутствие записей за измерение requests. Финальный прогон 2 PASS; старые FAIL не названы успешными.

## Непроверенное и границы вывода

- Реальный OpenRouter на французском внешнем сайте, языковая точность, сохранность чисел/терминов у живой модели и реальная скорость API не подтверждены без пользовательского ключа и конкретного платного теста. Browser smoke подтверждает локальную fixture и pipeline.
- Настоящий Sign in with ChatGPT, доступность плана, live ответ Luna 6, подписанная установка Firefox, публикация и пользовательский Chrome toolbar/permission dialog не проверены. Mock OAuth/Responses не подменяет эти результаты.
- В Firefox WebDriver Resource Timing показал только статические ссылки: число фактически запрошенных dynamic locale chunks отдельно не измерено. Firefox пакет содержит 28 chunks, немецкий/французский UI и локальный French pack работают offline; прямой счётчик загрузки есть только для Chromium.
- Проверки минимально заявленных версий Chrome 120/Firefox 142 на самих старых браузерах и полный WCAG/native-speaker audit не выполнялись.
