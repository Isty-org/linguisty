## Before → after

- Shared UI chunk 609 125 B → 260 289 B in the final build (−57.3%). Additional languages load locally on selection; concurrent loads are coalesced.
- Partial settings writes and restoration could bring back the old mode/key → a shared mutation queue and rollback of write attempts; after a restoration failure, the next command can retry it. Physical atomicity across two browser storage APIs remains the TD-001 limitation.
- Transport stopped an admissible batch at 35 s → the budget follows the finite batch deadline, up to 305 s including transport allowance; cancellation releases the wait and ignores a late response.
- Firefox 157.0.1 unloaded the background at 30 131 ms and interrupted the request → a single shared activity timer runs only during bounded requests. A 40-second response without early HTTP headers passed; after completion the background unloads normally again.
- Arbitrary API error text could retain short page fragments → the log accepts a bounded set of machine fields; old entries are sanitized before being returned to the UI and on writes. Storage, screen, and copying were checked.
- The QA instructions required retaining the provider message/request ID → they check that these are absent and that diagnostics are safe under the updated canonical specification.
