# Linguisty v0.4.9 — первый публичный релиз

Автор разработки: Никита Цыжман ([@tsyzhman](https://github.com/tsyzhman)).

Linguisty переводит веб-страницы через выбранную пользователем языковую модель. Первый GitHub-релиз сохраняет номер текущей разработки 0.4.9.

- Самостоятельные сборки Chrome 120+ и Firefox 142+ desktop.
- OpenRouter и OpenAI-совместимые API с собственным ключом пользователя; подключение подходящего плана ChatGPT через Sign in with ChatGPT.
- Перевод страницы и динамического текста, постепенный вывод, отмена и возврат оригинала.
- Ограниченный локальный кэш, 16 языков интерфейса, светлая и тёмная темы.
- Настройки локальны; собственного сервера и телеметрии Linguisty нет. Выбранный провайдер получает текст для перевода.

## Загрузка и установка

- `linguisty-0.4.9-chrome.zip`: распаковать, открыть `chrome://extensions`, включить режим разработчика и загрузить распакованную папку.
- `linguisty-0.4.9-firefox.zip`: распаковать, открыть `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение», выбрать `manifest.json`.
- `SHA256SUMS.txt`: SHA-256 обоих пакетов.
- GitHub Source code: полный исходный код и тесты из tag `v0.4.9`; пересборка через `npm ci` и `npm run build:chrome` / `npm run build:firefox`.

## Проверки и ограничения

Фактические результаты текущего прохода: [QA-RELEASE-2026-10-20](QA-RELEASE-2026-10-20.md). Автоматические provider/OAuth проверки используют mock-ответы.

Пройдено: typecheck и lint; 780 unit tests; 15 native tests; 9 manifest/hygiene tests; обе production-сборки; по 14 smoke checks в Chrome и Firefox; mock ChatGPT в обоих браузерах; 2 сценария длинного запроса. Mozilla Add-ons Linter: 0 errors / 0 notices / 0 warnings. Все 112 файлов пакетов сохранили исходные SHA-256 после браузерных проверок.

Firefox-пакет не подписан: временная установка исчезает после перезапуска браузера. Постоянная установка в обычный Firefox требует подписи Mozilla. Расширение не опубликовано в Chrome Web Store или Mozilla Add-ons.

Доступ через ChatGPT зависит от подходящего плана, разрешения OpenAI и ограничений аккаунта/приложения; работа для всех подписчиков не гарантируется. Реальный вход ChatGPT, платные API, смысловая точность перевода, ревью всех локализаций носителями и запуск на минимальных версиях браузеров в этом проходе не проверяются.
