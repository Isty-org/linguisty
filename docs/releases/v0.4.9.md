# Linguisty v0.4.9 — first public release

Developed by Никита Цыжман ([@tsyzhman](https://github.com/tsyzhman)).

Linguisty translates web pages using the language model selected by the user. The first GitHub release retains the current development version number, 0.4.9.

- Standalone builds for Chrome 120+ and Firefox 142+ desktop.
- OpenRouter and OpenAI-compatible APIs with the user's own key; connection to an eligible ChatGPT plan through Sign in with ChatGPT.
- Page and dynamic text translation, progressive output, cancellation, and restoration of the original.
- Bounded local cache, 16 interface languages, and light and dark themes.
- Settings are local; Linguisty has no server or telemetry of its own. The selected provider receives the text for translation.

## Download and installation

- `linguisty-0.4.9-chrome.zip`: extract it, open `chrome://extensions`, enable Developer mode, and load the unpacked folder.
- `linguisty-0.4.9-firefox.zip`: extract it, open `about:debugging` → This Firefox → Load Temporary Add-on, and select `manifest.json`.
- `SHA256SUMS.txt`: SHA-256 hashes of both packages.
- GitHub Source code: complete source code and tests from tag `v0.4.9`; rebuild with `npm ci` and `npm run build:chrome` / `npm run build:firefox`.

## Checks and limitations

Actual results of this pass: [QA-RELEASE-2026-10-20](../archive/QA-RELEASE-2026-10-20.md). Automated provider/OAuth checks use mock responses.

Passed: typecheck and lint; 780 unit tests; 15 native tests; 9 manifest/hygiene tests; both production builds; 14 smoke checks each in Chrome and Firefox; mock ChatGPT in both browsers; 2 long-request scenarios. Mozilla Add-ons Linter: 0 errors / 0 notices / 0 warnings. All 112 package files retained their original SHA-256 hashes after browser checks.

The Firefox package is unsigned: temporary installation disappears after a browser restart. Permanent installation in standard Firefox requires Mozilla signing. The extension is not published in the Chrome Web Store or Mozilla Add-ons.

ChatGPT access depends on an eligible plan, OpenAI authorization, and account/application restrictions; operation for every subscriber is not guaranteed. Real ChatGPT sign-in, paid APIs, translation accuracy, native-speaker review of all localizations, and execution on minimum browser versions were not checked in this pass.
