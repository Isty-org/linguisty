## Installation

Chrome: extract `linguisty-0.4.10-chrome.zip`, open `chrome://extensions`, enable Developer mode, and load the unpacked folder.

Firefox: extract `linguisty-0.4.10-firefox.zip`, open `about:debugging` → This Firefox → Load Temporary Add-on, and select `manifest.json`. The Firefox ZIP is unsigned; permanent installation requires Mozilla signing.

Package SHA-256 hashes are in `SHA256SUMS.txt`. Complete source code is available through GitHub Source code at tag `v0.4.10`; rebuild with `npm ci` and `npm run build:chrome` / `npm run build:firefox`.
