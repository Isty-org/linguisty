## Было → стало

- Общий UI chunk 609 125 B → 260 289 B в финальной сборке (−57,3%). Дополнительные языки загружаются локально по выбору; конкурентные загрузки объединены.
- Частичная запись настроек и восстановление могли вернуть старый режим/ключ → общая очередь изменений и rollback попыток записи; после отказа восстановления следующая команда может повторить его. Физическая атомарность двух browser storage API остаётся ограничением TD-001.
- Transport прекращал допустимый batch на 35 s → бюджет соответствует конечному deadline batch, до 305 s с транспортным запасом; отмена освобождает ожидание и игнорирует поздний ответ.
- Firefox 157.0.1 выгружал фон на 30 131 ms и обрывал запрос → один общий таймер активности только во время ограниченных запросов. 40-секундный ответ без ранних HTTP headers прошёл; после завершения фон снова штатно выгружается.
- Произвольный текст ошибки API мог сохранить короткие фрагменты страницы → журнал принимает ограниченный набор машинных полей; старые записи очищаются перед выдачей UI и при записи. Проверены storage, экран и копирование.
- Инструкция QA требовала сохранять provider message/request ID → проверяет их отсутствие и безопасную диагностику согласно обновлённому канону.
