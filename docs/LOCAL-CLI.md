# Linguisty через установленный CLI

Было: расширение вызывало OpenRouter или OpenAI-совместимый API с вашим ключом. Стало: дополнительно можно выбрать **Codex, Claude Code, Antigravity CLI или Grok Build**, используя официальный CLI, установленный и авторизованный на вашем компьютере.

Это именно инструменты пользователя: Codex CLI (включая бинарник в установке Codex desktop), Claude Code, agy Antigravity и grok Grok Build. Linguisty запускает отдельный короткий перевод. Вход выполняется в исходном CLI; расширение не управляет существующими чатами приложения.

Интерфейс, выбор модели, запуск, отмена и показ оригинала находятся в расширении. Chrome/Firefox не дают расширению напрямую запускать системные программы: для этого предусмотрен [Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging). Поэтому соединитель устанавливается один раз; затем браузер сам запускает его при запросе. Постоянно включённый терминал или отдельный сервер не нужны.

## Установка Windows

1. Установите новую сборку Linguisty для своего браузера. Для Chrome сохраните прежнюю папку распакованного расширения и обновите её: изменение пути меняет ID и отдельные настройки.
2. Установите нужный официальный CLI и войдите в него обычным способом. Antigravity нужен с headless-командой agy; одна установка редактора без CLI не подтверждает доступность этого режима. Наличие только обычного Grok-чата также не означает наличие Grok Build.
3. Соединитель требует [Node.js 22.12+](https://nodejs.org/en/download). Если он уже установлен, переустанавливать его не нужно.
4. В настройках Linguisty выберите CLI. Для Chrome скопируйте показанный «ID расширения для установки соединителя».
5. Распакуйте .output/linguisty-0.3.0-cli-helper.zip и дважды откройте INSTALL.cmd. Для Chrome вставьте ID; для Firefox можно оставить поле пустым. Администратор не нужен.
6. Нажмите «Сохранить настройки» и примите разрешение связи с локальными программами. Нажмите «Проверить подключение».
7. Оставьте модель default или укажите доступный CLI ID. Откройте страницу и нажмите «Перевести страницу».

Для разработки установщик находится в native-host/install.ps1. Из PowerShell: powershell.exe -NoProfile -ExecutionPolicy Bypass -File native-host/install.ps1 -ChromeId ID_ИЗ_НАСТРОЕК; для одного Firefox — -FirefoxOnly.

Установщик копирует соединитель в %LOCALAPPDATA%\Linguisty\native-host и регистрирует **только** com.linguisty.cli в HKCU для браузеров. Настройки API и вход сторонних CLI сохраняются. Для отмены регистрации запустите установщик с -Uninstall: он сохраняет установленные файлы и чужие аккаунты.

## Что проверяет кнопка

«Соединитель подключён, CLI найден. Вход в аккаунт и ответ модели не проверялись» означает ровно это. Кнопка ищет исполняемый файл через локальную файловую систему; запроса модели нет. «Загрузить список моделей» в CLI предлагает default, без обещания каталога моделей аккаунта. ID можно задать вручную.

Если соединитель не найден, повторите установку с актуальным Chrome ID и перезапустите браузер. Если CLI не найден, установите официальный CLI и повторите установку соединителя. Если CLI просит вход, выполните вход в самом CLI.

## Ограничения

CLI работает на вашем компьютере, но эти модели работают в облаке. Перевод расходует лимиты и бюджет аккаунта выбранного инструмента; офлайн-перевод и бесплатный неограниченный доступ не обещаются. Linguisty не читает файлы токенов, не копирует аккаунты и не подменяет официальный CLI.

На каждый пакет текста запускается новый процесс; это медленнее прямого API. CLI выполняет один перевод одновременно, постепенно появляющийся текст отключён, таймаут при выборе — 120 секунд. Кэш и дедупликация уменьшают повторные обращения. Отмена останавливает дальнейшую работу расширения, но не гарантирует отмену уже учтённых расходов в облаке.

Поддержан Windows установщик. Совместимость конкретной версии CLI и реальный ответ модели требуют отдельной проверки. В этой приёмке живые модельные запросы не выполнялись; точные результаты — [QA-CLI](QA-CLI.md). Сторонний CLI может самостоятельно сохранять историю/кэш, которые Linguisty не очищает.
