# WI-029: Загрузка только выбранного словаря UI

- Kind: `fix`
- Canon action: `none`

## Outcome

Закрыть TD-002: popup/options/страница подключения загружают выбранный локальный словарь с безопасным fallback, без общего пакета всех 16 словарей.

## Specs

- Governing: `spec://modules/interface/FEAT-003-controls#languages`
- Constraint: `spec://common/PROP-002-quality#resources`
- Constraint: `spec://modules/interface/FEAT-003-controls#errors`

## Scope

- Assigned paths: `src/ui/**`, `entrypoints/popup/**`, `entrypoints/options/**`, `entrypoints/codex/**`, `tests/ui/**`, этот WI.
- In: локальная загрузка словарей, переключение языка, fallback, регрессии startup и гонок.
- Out: зависимости, общие контракты, конфигурация сборки, канон и операционные документы.

## Acceptance

- [x] Выбранный язык и auto определяются как раньше; доступны все 16 языков.
- [x] Нет eager импорта всех словарей в production UI; ошибка загрузки имеет безопасный fallback. Production chunks обеих платформ и фактические Chrome resource requests проверены координатором и WI-031.
- [x] Смена языка и unmount не оставляют stale state/listeners или неограниченный cache.
- [x] Осмысленные UI tests проходят, Result содержит было → стало и ограничения.

## Result

Приёмка координатора 2026-10-12: обе production builds 0.4.7 PASS; общий UI chunk 609125 → 259999 bytes (-57.3%), 14 ленивых языков в 28 локальных chunks. Callback entry 843 bytes и compact labels 11491 bytes не выросли. Проверки manifest/ресурсов обеих платформ PASS (56 файлов каждая). Chrome browser evidence: eager locale requests=0, выбор de загружает только de, fr только fr, включая offline; Firefox подтвердил locale/offline, Resource Timing модульные запросы там не показывает. Интеграционный Vitest: 751 tests / 48 files PASS; typecheck/lint PASS. Точная граница сетевого измерения отражена в WI-031.

Было → стало: общий UI импортировал 16 полных словарей, а также массивы CLI/ChatGPT строк всех языков → английский fallback и компактный русский источник остаются синхронными, остальные 14 полных словарей и соответствующие CLI/ChatGPT строки загружаются локальными динамическими imports по выбранному языку. Прямые синхронные потребители получают безопасный английский текст до готовности словаря или при отказе его chunk; React UI затем обновляется. Язык документа во время ожидания и при отказе соответствует отображаемому английскому fallback. Callback входа ChatGPT сохраняет отдельную компактную таблицу и не импортирует полный UI.

Смена языка использует актуальный requested locale; завершение прежней загрузки не заменяет новый выбор. Одинаковый in-flight import дедуплицируется; кэши ready/pending ограничены 16 объявленными локалями, pending удаляется после завершения. Подписки на languagechange/storage/готовность словаря освобождаются при unmount. Отказ не кэшируется как успешный словарь.

Проверено: `tsc --noEmit` PASS; eslint затронутого UI и тестов PASS; `vitest run tests/ui --maxWorkers=2` 10 файлов / 88 тестов PASS. Новые тесты покрывают задержанную загрузку, dedup, смену языка до завершения, отказ chunk и unmount до завершения. Тест полноты и placeholder-переменных проходит для всех 16 локалей. 16 файлов дополнительных строк имеют 16 уникальных SHA-256; прежние общие массивы удалены. Промежуточный/финальный снимок свободной RAM 12 250 392 / 11 463 172 KiB; `.cache` 5 746 / 5 734 файлов и 243 012 338 / 242 567 580 B; причина изменения размера на фоне параллельной работы не установлена, кэш не удалялся. Собственных watch-процессов и временных скриптов не оставлено; чужие процессы сохранены.

Ограничение: production builds Chrome/Firefox, размер UI/locale/callback chunks и проверку их packaging выполняет координатор. До этого TD-002 не объявляется закрытым, WI не архивируется. Нативная языковая редактура 16 переводов и реальный вход ChatGPT этим изменением не проверялись.
